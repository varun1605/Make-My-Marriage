## Scope and environment

This records direct Chrome UI testing of the implemented public homepage,
signup, login, protected account page, current-user lookup and logout. Homepage
wedding planning cards are illustrative previews; wedding creation, events,
tasks, guests, expenses, vendors, websites, livestreams, galleries and password
recovery do not yet have functional application workflows to test.

- Google Chrome on macOS, in a separate Incognito window.
- Isolated application at `http://127.0.0.1:3001`, with a temporary MongoDB replica
  set and disposable test identity. No developer Atlas records or environment
  files were used. The normal development server was left running.
- Snapshot of the working tree, including the earlier credential-form fix:
  75 source/asset/configuration files compared with no differences.
- Next.js development mode with webpack, using the installed dependencies.
  This is not production HTTPS/cookie-delivery certification or a Turbopack test.
- Desktop screenshots and Chrome responsive emulation at 390 × 844. Emulation
  does not establish behaviour on a physical phone or in Safari/Firefox.
- Homepage checks began on November 3; auth and responsive checks continued on
  November 4. Test passwords, cookies and session identifiers are not recorded.
